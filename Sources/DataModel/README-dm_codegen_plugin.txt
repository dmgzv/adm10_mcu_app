Prerequisites:
==============
	Python 2.7
	pyang plugin


Environment:
============
(1) Install python 2.7
(2) Install pyang plugin using the following command.
	pip install pyang
(3) Create a directory anywhere and place the dm_codegen_plugin.py in that
    directory.
(4) Run the following command to generate the data model
	$PYTHON_INSTALL_DIR/python $PYTHON_INSTALL_DIR/scripts/pyang --plugindir $PLUGIN_DIR/plugin -V -f dm_codegen_plugin --pack-struct --dm-name <dm-name> <yang-file-1> <yang-file-2> ...

	Note 1: Option --pack-struct is optional
	Note 2: The command needs to be executed for each data model (for one
		card) separately and all YANG files required for that model
		needs to be specified in the command line. Specify all imported
		modules first, then specify card module.  Note 3:  The order of
		card modules is important as it decides the order of structure
		elements in the data model.  Changing the order generates
		binary incompatible data model.
	Note 4: Usually all card models import ipg-common and ipg-system yang
		models. Specify them if card model needs them.
	Note 5: The card model might also need hidden atributes (for example
		admin-state, service-state). Create a separate YANG model for
		them and specify the model as input to the command. See
		ipg-hidden@2019-08-28.yang in SampleYangFiles directory.
	Note 6: The following files will be auto-generated:
		dm_types.h
		dm_<dm-name>.h
		dm_<dm-name>.c

   A sample batch script adm10.bat

Tested Environment:
===================
	Tested with Python 2.7.13, pyang 2.0.1 on MS Windows machine.
